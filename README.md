# RETROPOLIA — сборка и запуск на Windows

Онлайн-игра на 2–4 игроков: монополия, где вместо покупки клеток игроки проходят челленджи в эмуляторе NES/SEGA. В комплекте: редактор карт, редактор тайлов, редактор заданий, тестовый стенд эмулятора и синхронизация партий (PeerJS P2P + резервный tab-канал).

---

## 1. Что нужно установить

1. **Node.js LTS (v20 или v22)** — скачать с [nodejs.org](https://nodejs.org), поставить «как обычно» (Next → Next). Он включает `npm`.
2. Проверить в PowerShell / CMD:

```
node -v
npm -v
```

Обе команды должны напечатать версии.

## 2. Установка зависимостей и запуск (режим разработки)

Откройте PowerShell или CMD в папке проекта (в Проводнике: зажать Shift + правый клик → «Открыть окно PowerShell здесь», либо `cd путь\к\retropolia`):

```
npm install
npm run dev
```

Откройте в браузере адрес из консоли (обычно **http://localhost:5173**). Готово — игра запущена.

> При первом запуске Windows может спросить разрешение для сетевого доступа Node — разрешите, если хотите играть по локальной сети.

## 3. Продакшен-сборка

```
npm run build
```

Готовый сайт появится в папке `dist/`. Чтобы открыть его локально:

```
npx serve dist
```

(или `npx http-server dist`) — адрес напечатается в консоли, например http://localhost:3000.

## 4. Как играть

| Режим | Как |
|---|---|
| **Тест 1 игрока** | «Создать игру» → выбрать карту → «Начать» без игроков. Подтверждения заданий автоматические. |
| **2 игрока, один ПК** | Открыть игру в **двух вкладках браузера**: первая — «Создать игру», вторая — «Подключиться» с кодом комнаты. Работает через встроенный tab-канал, мгновенно. |
| **Локальная сеть** | Запустить `npm run dev -- --host`, игроки заходят по `http://ВАШ_IP:5173` (IP виден командой `ipconfig`). |
| **Онлайн через интернет** | Каждый игрок открывает игру у себя (локально или на хостинге) и вводит один и тот же код комнаты. Знакомство идёт через публичный облачный брокер PeerJS — **проброс портов не нужен**. При очень строгих NAT-сетях P2P-канал может не пробиться — тогда используйте вариант с хостингом ниже. |
| **Публикация (по желанию)** | Загрузите содержимое `dist/` на Netlify / Vercel / GitHub Pages / Cloudflare Pages — бесплатно, HTTPS включён, онлайн-игра стабильнее. |

## 5. Ромы и сохранения

- Раздел **«Запуск эмулятора»** → «Загрузить ром»: поддерживаются `.nes` (NES, играется прямо сейчас, ядро jsnes) и `.md/.gen/.sms` (SEGA — файлы сохраняются в библиотеку, ядро SEGA подключается отдельно).
- Играете, доходите до нужного места → **«Сохранить состояние»** → слот. Неверные слоты удаляются кнопкой корзины.
- В **редакторе заданий** к ячейке привязывается пара «ром + слот», плюс название, описание и картинка.
- «Папки шаблонов» из замысла реализованы через саму библиотеку: ромы со слотами 1, 2, 3… — это и есть уровни-шаблоны, которые игроки выбирают прямо во время партии (кнопка «Новое задание» после захвата ячейки).
- **Важно:** используйте только ромы, права на которые у вас есть. Игра ничего не распространяет — файлы загружаете вы сами.

## 6. Где хранятся данные

Всё (тайлы, карты, ромы, сохранения, сессии) лежит в **IndexedDB браузера** на вашей машине:

- у каждого браузера — своя библиотека;
- карта при создании онлайн-комнаты **передаётся всем игрокам автоматически** (версия протокола должна совпадать);
- полная очистка — «Опции» → «Очистить библиотеку».

## 7. Если что-то не так

- `npm install` падает — обновите Node до LTS и повторите; при проблемах с сетью: `npm config set registry https://registry.npmmirror.com`.
- Порт занят — `npm run dev -- --port 5180`.
- Игроки не видят друг друга онлайн — сверьте, что версии игры одинаковые, код введён верно; для теста используйте две вкладки одного браузера (tab-канал работает всегда).
- Нет звука/управления в эмуляторе — кликните один раз по странице (браузеры требуют первое действие пользователя для аудио).

## 8. Команды для справки

```
npm install      # установить зависимости
npm run dev      # режим разработки (горячая перезагрузка)
npm run build    # сборка в dist/
npx serve dist   # раздать собранную версию локально
npm run typecheck# проверка типов TypeScript
```
