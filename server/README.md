# RETROPOLIA — свой реле-сервер (PeerJS)

Аналог «сервера TeamSpeak»: один публичный адрес, который знают все игроки.
Свой IP раздавать никому не нужно — только имя сервера.

## Вариант 1 — Glitch (самый простой, без установки, бесплатно)

1. Откройте https://glitch.com → «Sign in» (можно войти через Google — бесплатно).
2. «New project» → **«glitch-hello-node»** (шаблон с Node.js).
3. В открывшемся редакторе:
   - удалите файл `server.js` шаблона и вставьте содержимое **нашего** `server.js`;
   - откройте `package.json` и в секцию `dependencies` допишите:
     ```json
     "express": "^4.19.2",
     "peer": "^1.0.2"
     ```
     (Glitch сам установит пакеты и перезапустит проект.)
4. Слева вверху — имя проекта, например `moj-relay`. Адрес сервера:
   **`https://moj-relay.glitch.me`**
5. Проверьте: откройте `https://moj-relay.glitch.me/health` — должно быть `{"ok":true,...}`.

> Бесплатный проект Glitch «засыпает», когда им не пользуются, и просыпается
> при первом подключении (~30–60 секунд). Пока комната открыта — сервер не спит.

## Вариант 2 — Render.com

1. https://render.com → бесплатный аккаунт → «New» → **«Web Service»**.
2. Загрузите эту папку как репозиторий (или подключите GitHub).
3. Build command: `npm install`, Start command: `npm start`.
4. Получите адрес вида `https://retropolia-relay.onrender.com`.

## Вариант 3 — локально (одна сеть, без интернета)

```
cd server
npm install
npm start          # поднимется на порту 9000
```

Адрес для игры — `IP_этого_компьютера:9000` (IP: `ipconfig` → строка «IPv4-адрес»).

## Как подключить игру к серверу

На **всех** компьютерах: «Опции» → поле **«Свой реле-сервер»** → впишите адрес:

- Glitch/Render: `https://moj-relay.glitch.me` (или без `https://` — просто имя)
- локальный: `192.168.1.10:9000`

Пустое поле = публичное облако `0.peerjs.com` (работает, но иногда перегружено).
